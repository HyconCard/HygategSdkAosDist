# HygateG Android SDK

HygateG 6축 IMU 비콘 장비를 Android 앱에서 제어하기 위한 BLE SDK 배포 저장소입니다.

## 다운로드

최신 버전은 **[Releases](../../releases)** 에서 받으세요.

| 파일 | 내용 |
|---|---|
| `hygateg-sdk-<버전>.zip` | SDK 본체. 사용 설명서(`README.md`)와 라이브러리가 들어 있습니다 |
| `hygateg-sdk-sample-<버전>.zip` | 예제 앱. 압축을 풀고 Android Studio에서 열면 바로 빌드됩니다 |

## 사용법

`hygateg-sdk-<버전>.zip`을 풀면 들어 있는 `README.md`에 설치·권한·API 사용법이 정리돼 있습니다.
처음 연동하신다면 예제 앱을 함께 받아 실기기에서 실행해 보시는 편이 빠릅니다.

## 요구 사항

- Android 7.0 (API 24) 이상
- Kotlin (coroutines / Flow)
- BLE를 지원하는 실기기 (에뮬레이터에서는 동작하지 않습니다)
